# Student Management System

A Java and MySQL based backend project designed to manage student records efficiently using CRUD operations and database connectivity.

---

## 🚀 Features

- Add Student Records
- Update Student Information
- Delete Student Records
- Search Student Details
- Database Connectivity using JDBC
- Input Validation and Error Handling

---

## 🛠 Technologies Used

- Java
- JDBC
- MySQL
- Object-Oriented Programming (OOP)
- NetBeans IDE

---

## 📚 Concepts Covered

- CRUD Operations
- Database Management
- JDBC Connectivity
- Exception Handling
- OOP Concepts
- SQL Queries
